How it works

  • Agent ID gate. Minting requires a SPACE ID Agent ID NFT — the contract checks that your wallet owns the Agent ID you enter.
  • Instant delivery. Pay in USDT and receive 1 AICENT per share in the same transaction.
  • 80 / 20 split. 80% of every payment stays in the mint contract as pool reserve; 20% goes to the treasury wallet.
  • Fixed supply. 4,440,000 shares maximum, 10 per Agent ID. When they are gone, minting ends.
